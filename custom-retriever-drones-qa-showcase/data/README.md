# Data Directory

Place the Drones markdown files here when running the sanitized script locally.

Supported layouts:

```text
data/single_newspieces.zip
```

or:

```text
data/single_newspieces/
  article-1.md
  article-2.md
```

or:

```text
data/
  article-1.md
  article-2.md
```

The original article files are intentionally not committed to this repository. Keep source data out of version control unless you have permission to publish it.
